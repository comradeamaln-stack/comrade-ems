# Comrade EMS - Enquiry Management System

A modern, full-featured CRM and Enquiry Management System built with Next.js 16, featuring automated notifications, lead scoring, and comprehensive business management tools.

## 🚀 Features

- **Enquiry Management**: Track and manage customer enquiries with automated lead scoring
- **Appointment Scheduling**: Schedule and manage appointments with automated reminders
- **Service Request System**: Handle customer service tickets with email notifications
- **Collection Management**: Track payments and collections
- **Team Management**: Manage staff with role-based access control
- **Performance Analytics**: Track team performance and sales metrics
- **Automated Notifications**: Email and WhatsApp notifications (configurable)
- **Authentication**: Secure login system with admin and staff roles

## 🛠️ Tech Stack

- **Framework**: Next.js 16.1.6 (App Router)
- **Database**: SQLite with Drizzle ORM
- **Styling**: Vanilla CSS with modern design system
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Email**: Nodemailer

## 📦 Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables (optional):
   Create a `.env.local` file:
   ```env
   EMAIL_HOST=smtp.gmail.com
   EMAIL_PORT=587
   EMAIL_USER=your-email@gmail.com
   EMAIL_PASSWORD=your-app-password
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000)
